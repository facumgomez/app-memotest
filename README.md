# 🧠 Memotest Game

Proyecto desarrollado con **React Js** que implementa el clásico juego de memoria (Memotest).  
El objetivo es encontrar todas las parejas de fichas en el menor tiempo posible.

Este proyecto fue creado para practicar desarrollo con componentes, manejo de estado y buenas prácticas en React Js.

---

## 🚀 Demo

🔗 Deploy:  
https://memotestfood.vercel.app/

---

## 🛠 Tecnologías utilizadas

- React Js
- JavaScript (ES6+)
- HTML5
- CSS3
- Hooks (useState, useEffect)
- Componentes funcionales

---

## 🎮 Funcionalidades

- Juego interactivo de memoria.
- Renderizado dinámico de fichas.
- Sistema de comparación de pares.
- Manejo de estado con React Hooks.
- Reinicio de partida.
- Diseño responsive.
- Deploy en plataforma web.

## ⚙️ Instalación y ejecución local

1. Clonar el repositorio:

```
git clone https://github.com/facumgomez/app-memotest.git
```

2. Instalar dependencias:

```
npm install
```

3. Ejecutar en modo desarrollo:

```
npm run dev
```

4. Abrir en el navegador la URL que indique Vite.
